# Calculadora Científica Premium - Flutter

Una aplicación de calculadora avanzada desarrollada en **Flutter** y **Dart**, diseñada con los más altos estándares de **Material Design 3**. Este proyecto va más allá de las operaciones aritméticas básicas, incorporando análisis matemático en tiempo real y una arquitectura de software escalable.

## Características Principales (Features)

*   **Operaciones Básicas y Avanzadas:** Suma, resta, multiplicación, división, potenciación, radicación y logaritmos.
*   **Análisis Dinámico de Números:** 
    *   Verificación de paridad (Par / Impar).
    *   Identificación de la Secuencia de Fibonacci.
*   **Trigonometría:** Cálculo de Seno, Coseno y Tangente.
*   **Diseño Premium UI/UX:** Interfaz fluida basada en paletas tonales de Material 3, contenedores redondeados y respuestas visuales instantáneas al usuario.
*   **Inputs Reactivos Paralelos:** Soporte simultáneo para el ingreso fluido del Número 1 y Número 2 sin bloqueos de interfaz.
